## 五、今日热点主线判读

1. **图原生上下文形成四方合围，向 RAG 的向量路线正面施压。** graphify（+454 / 总 10.8 万，tree-sitter 确定性 AST、36 语言、每条边带 EXTRACTED/INFERRED/AMBIGUOUS 溯源标签、不用向量库，社区实测 71.5× 与 79× token 缩减）、GitNexus（+48，纯浏览器端零服务器）、周榜 semantica（+4,304，可问责与溯源）、OpenViking（日 +803 / 周 +985，云侧自进化上下文数据库）分别从本地、浏览器、可审计性、云服务四个位置切入同一问题。graphify 的血统值得注意：它是 Karpathy「让 LLM 可读的代码库 wiki」构想的开源答案，把上下文压缩从检索问题重构为图遍历问题。

2. **但向量检索并未退场，而是在换底座——这是路线之争而非替代。** turbovec（+734，TurboQuant 量化 + Rust 内核 + Python 绑定，当日增量占其总量 4.7%）与 milvus（+23）同日在榜。判断「向量已死」缺乏数据支撑；更准确的描述是结构化图谱吃掉了「代码/文档等有显式边的语料」，向量继续守住无显式结构的语料。

3. **Agent 记忆层进入厂商与路线双重竞争。** 火山引擎 OpenViking（统一 Memory/RAG/Skills 于单一数据库抽象）对上 claude-mem（+142 / 总 9.1 万，全量记录 + AI 压缩 + 按需注入）、engram（+25，Go 二进制 + SQLite FTS5 + MCP 的极简本地方案）、letta-code（+15，有状态 Agent 内建身份与学习）。四者在「结构化程度」与「接入成本」上做了完全不同的取舍，尚无收敛迹象。
