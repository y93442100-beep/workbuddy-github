## 一、AI Coding 方向

### 1. Cursor 3.5 推出云端 Agent 并重构定价：从"编辑器"转向"Agent 编排台"

7 月 20 日，Cursor 更新定价体系（futureproofing.dev 实测）：取消原有分层订阅，统一为 Pro / Pro+ / Ultra 三档，基础档 $20/月、超出部分按用量计费。此前 5 月发布的 Cursor 3.5 已将"Agents Window"设为首要界面、文本编辑器退居其次，并推出 Cloud Agents——运行在隔离云 VM 中、拥有完整终端与浏览器权限，最多可并行 10 个、跨多仓库异步汇报结果；本地 /multitask 可同时将任务分发到最多 8 个隔离 Git 分支的子 Agent。

**值得关注的原因：** Cursor 的产品哲学从"IDE 内嵌 AI"彻底转为"以 Agent 编排为核心"，定价也从席位制转向用量制。这反映出 AI 编程工具的竞争焦点正从"补全质量"迁移到"可并行 Agent 数量、云端算力与成本治理"，对企业采购与计费模式都有直接影响。

### 2. Claude Code 7 月更新：多 Agent 稳定性与成本护栏成主线

7 月，Anthropic 为 Claude Code 推出多项稳定性更新（vortx.ch 汇总）：新增 /fork 命令将对话复制到后台会话、/subtask 取代原内联子 Agent；引入会话级多 Agent 控制与更深 MCP 集成；并设置会话级上限（WebSearch 默认 200 次、子 Agent 派生默认 200 个）以遏制失控的 Agent 循环导致的账单暴涨；运行超过 2 分钟的 MCP 调用自动转入后台，保持主会话响应。

**值得关注的原因：** 当多 Agent 并行成为常态，工程挑战从"模型能力"转向"任务拆解、权限控制、成本控制与验收体系"。Claude Code 主动给 Agent 加"刹车"，说明行业已意识到无约束自主性是规模化部署的真实风险，而非宣传噱头。

### 3. 谷歌开源 Agents CLI：为 Claude Code / Codex 注入"开发到运维"工程工具链

7 月 16 日，谷歌开源 Agents CLI 在 GitHub 收获 5.1k stars（腾讯网 vibe coding 日报）。该工具为 Claude Code、Codex 等编程智能体提供 CLI + 7 项 Skills 工具包，覆盖需求梳理、ADK 代码生成、评测、部署到 Google Cloud 及可观测性，把 Agent 从开发到运维的整条链路交给 AI 推进。

**值得关注的原因：** 编程 Agent 的竞争正从"模型+编辑器"扩展到"工程化工具生态"。谷歌以开源方式把自家云原生工具链嵌入第三方 Agent，实质是在争夺"Agent 工作流标准"的话语权，也降低了开发者把 Agent 接入生产链路的门槛。

### 4. AI 编程 Agent 供应链攻击集中爆发：Friendly Fire 与 AsyncAPI 投毒

7 月 9–14 日，两类针对编程 Agent 的供应链攻击被密集披露。AINow 研究院披露代号 Friendly Fire 的攻击：通过开源代码供应链劫持 Claude Code 与 Codex，在用户执行"自动安全审计"时利用自动模式静默执行恶意脚本获得 RCE，覆盖 Claude Sonnet 4.6/5、Opus 4.8 及 GPT-5.5（看雪学苑）。7 月 14 日 Datadog 发现 AsyncAPI 四个 npm 包（周下载合计超 300 万次）被植入恶意代码——攻击者攻破其 CI/CD 流水线、盗用发布凭证推送带毒版本，窃取 SSH 密钥、npm token 与 API 密钥后回传。同期 GitHub Copilot CLI、Claude Code、OpenAI Codex 密集发布安全更新收紧工具权限。

**值得关注的原因：** AI 编程 Agent 因"默认信任合法来源、自动执行 npm install、后台静默运行"的特征，成为供应链攻击的"完美通道"而非单纯受害者。Snyk 数据显示近 12 个月利用自动化工具作传播渠道的供应链攻击增长 340%。安全范式必须从"行为层护栏"（拦 rm -rf）升级到"信任层治理"（依赖签名、来源验证、工具面收敛）。

## 二、具身智能方向

### 5. WAIC 2026：具身智能"去表演化"，量产与部署态元年到来

7 月 17–20 日，2026 世界人工智能大会（WAIC）在上海举行，具身智能首次独立成馆（H3），汇聚全国 200 余家上下游企业、超 300 台真机。最大变化是机器人不再炫技跳舞，而是把工厂产线、仓储货架、咖啡吧台搬进展厅真实作业：智元远征 A3 Ultra（8 小时续航、10 秒快换电）联合京东物流完成重物料搬运，60 台同系列机器人承担全场导览；宇树科技首公开无人工厂沙盘、2026 年目标出货 1–2 万台；傅利叶 GR 系列演示柔性衣物折叠与精密装配。技术栈上 VLA（Vision-Language-Action）端到端架构成为主流，Physical Intelligence 的 π0.7 被称机器人领域"GPT-3 时刻"，腾讯 HyVLA-0.5 长时程双臂任务成功率达 94%–99%。工信部预计 2026 年人形机器人整机产量有望突破 10 万台。

**值得关注的原因：** 行业从"全场景泛化"转向"先深耕单一场景、再迭代全域能力"的务实路径，形成商用服务、标准工业、特种场景三层落地格局。2026 年被称为"部署态元年"与"量产元年"双重叠加，具身智能正从愿景变为紧迫的产业命题。

### 6. IDC：中国具身智能支出五年激增约 55 倍，年复合增长率 94%

IDC 在 WAIC 期间披露数据（证券时报）：未来五年中国具身智能支出将从 14 亿美元激增至 770 亿美元，年复合增长率高达 94%；中国凭借完整供应链与丰富应用场景，将持续领跑全球产业。四足机器人工程化成熟度最高、已成盈利模式较清晰的品类（2025 年全球出货约 6 万台）；轮式/轻量人形商用服务机器人部署门槛更低，成为本届展会另一增长主力。

**值得关注的原因：** 资本与产能正在以指数级速度涌入，但"数据有效供给"成为新瓶颈——光轮智能指出今年具身数据需求是去年的百倍甚至千倍，而有效数据须同时满足高质量、大规模、多样性三条件，仿真评测被视为当前最优解。数据基础设施公司将随产业扩张同步受益。

## 三、基础模型方向

### 7. Claude Sonnet 5 发布：1M 上下文、SWE-bench 89.4% 反超旗舰

7 月 1 日，Anthropic 推出 Mythos 架构的中端主力模型 Claude Sonnet 5：1M token 上下文、128K 最大输出（较 Sonnet 4.6 翻倍），在 SWE-bench Verified 上取得 89.4%，略超旗舰 Claude Opus 4.8 的 88.6%（Opus 4.8 仍在 GPQA Diamond 领先，93.6% vs 92.0%）。首发优惠价 $2/$10 每百万 token，9 月 1 日后调整为 $3/$15。同日 Claude Fable 5 因美国商务部出口管制审查结束恢复全球访问。

**值得关注的原因：** Sonnet 5 以中端定价拿到旗舰级编码表现，进一步压缩"锁模型"的性价比空间，也印证了编程 Agent 的模型底座正快速同质化——这正是多模型路由（见趋势 3）能成立的前提。

### 8. GPT-5.6 与 Grok 4.5 密集发布，前沿模型进入"政府审查门控"时代

6 月 26 日 OpenAI 启动 GPT-5.6 系列（Sol / Terra / Luna）有限预览：采用"代数+能力档"新命名，Sol 旗舰支持 ultra 多智能体模式，定价 $5/$30 每百万 token，初期仅向约 20 家合作伙伴开放 API 与 Codex，且需经美国政府安全审查（stackspend 简报）。xAI 的 Grok 4.5 于 7 月 8 日开放，500K 上下文、定价 $2/$6。同期 Claude Fable 5 因 6 月 12 日出口管制令被暂停对外国人访问、7 月 1 日恢复，标志"你能合法使用哪款模型"首次成为政府议题而非单纯定价问题。

**值得关注的原因：** 前沿模型的发布路径已被政府直接介入——自愿预审行政令 + 出口管制令迫使商业发布暂停。团队在规划模型依赖时，必须将"能力、成本、可及性（access）"三者一并纳入评估，地理与合规变量成为架构决策的一部分。
