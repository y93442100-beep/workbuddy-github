# 今日 AI 动态速览（2026年7月22日）

> 由 WorkBuddy 整理归档 · 覆盖 AI Coding 与具身智能两大方向 · 均为 2026 年 7 月中旬发生的重大事件。

---

## 一、AI Coding 方向

### 1. SpaceX 600 亿美元收购 Cursor，AI 编程赛道迎来最大并购案

7 月 13 日，马斯克旗下 SpaceX 以全股票交易收购 AI 编程工具 Cursor，交易价值 600 亿美元，成为 AI 编程领域迄今最大收购案。Cursor 同日发布与 Git 兼容的代码托管平台 Origin，底层逻辑专为智能体主导的开发时代设计；同时收购了开源编程助手 Continue，并正在开发名为 Sand 的通用型 AI 智能体，从"写代码工具"迈向"日常生产力助手"。

**值得关注的原因：** 这笔交易标志着 AI 编程工具从创业赛道进入巨头整合阶段。Cursor 被 SpaceX 收编后，将与 Grok 4.5 模型深度协同，AI 编程工具的竞争从"产品力"升级为"模型+工具+生态"的全面战争。

### 2. Claude Code 创始人：软件开发两年连跳两级，多 Agent 协作成为新范式

7 月 20 日，Claude Code 创建者 Boris Cherny 在 Bloomberg 访谈中指出，软件开发在两年内经历了两次范式跃迁：第一次是开发者把编码任务交给模型，第二次是人只需给出目标，由一组 Agent 协同完成开发。据他估算，Anthropic 内部约 90% 的代码已由 Claude Code 完成，企业客户从"每人运行 1 个 Claude"发展到同时运行上千个。

**值得关注的原因：** 这揭示了 AI 编程正从"辅助"走向"主导"。当多 Agent 并行成为常态，任务拆解、权限控制、验收体系和成本管理将成为新的工程挑战，软件开发的生产关系正在被根本性重构。

### 3. AI 编程工具"锁模型"商业模式瓦解，多模型路由成为新趋势

7 月中旬，qwen-code、OpenOcta、OpenSquilla 等开源项目几乎同时发布新版本，核心指向同一方向：将"背后用什么模型"从核心竞争力变为可插拔的配置项。OpenSquilla 的智能路由层按任务难度自动选择模型，综合成本下降 60%-80%。同期，GPT-5.6 与 Claude Fable 5 在 SWE-bench 上差距不到 3 分，DeepSeek V4 Pro 以 GPT-5.6 十分之一的价格杀入第一梯队。

**值得关注的原因：** 当模型间性能差距缩小到个位数百分比，"绑定单一模型"从技术优势变为经济负担。AI 编程工具的竞争重心正从"模型能力"转向"工程化治理、安全合规与成本优化"，开源框架正在抓住这个裂缝重塑格局。

### 4. Coding Agent 安全问题集中爆发：供应链攻击与 0-day 漏洞

7 月 14 日，攻击者入侵 AsyncAPI 的发布管道，向 npm 推送了 5 个木马化包；同日，Cursor 被披露存在 0-day 漏洞（git.exe 在仓库根目录自动执行，已 7 个月未修复）；GitHub Copilot CLI、Claude Code、OpenAI Codex 在同一周内密集发布安全更新，收紧 Agent 的工具调用权限。研究人员还提出"Agent 数据注入攻击（ADI）"新类别，利用机器可解析的元数据绕过现有防护。

**值得关注的原因：** 随着 Coding Agent 被广泛部署到真实开发流程中，其权限边界和供应链安全已成为最紧迫的风险。安全从"锦上添花"变为"准入门槛"，企业在采纳 AI 编程工具时必须将 Agent 审计、工具面收敛和供应链验证纳入核心评估维度。

## 二、具身智能方向

### 5. WAIC 2026：具身智能从"会表演"到"会干活"，进入物理智能交付元年

7 月 17 日-20 日，2026 世界人工智能大会（WAIC）在上海举行，具身智能展区汇聚超 200 家企业、300 余台机器人。本届大会最大变化是机器人不再只是"炫技"——跳舞、翻跟头，而是真正被推入真实场景"上岗"：优艾智合的人形机器人在微缩产线完成物料拣选配送，仅需 50 条数据训练即达 90% 成功率；智元与京东物流合作的机器人在真实仓储中 24 小时搬运码垛；千寻智能的 Moz1 机器人能自主完成"整理客厅"全流程并动态应对干扰；灵心巧手展示了"机器人组装机器人"的全自动产线。触觉感知被业内视为下一阶段最具突破潜力的技术维度。

**值得关注的原因：** 行业衡量标准从"能不能做"变成"能不能持续做、大批量做"，标志着具身智能正式迈过实验室门槛。小样本训练（50 条数据即上岗）、长程推理与动态调整、以及"机器人自造机器人"的路径，正在从根本上改变机器人产业的成本结构和扩张逻辑。2026 年被定义为"物理智能规模化交付元年"，商业化落地已进入加速期。
